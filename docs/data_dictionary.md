# Data dictionary

Generated by `python -m healthbridge.dictionary` from the live schema; column names, types and nullability cannot drift from the database. Descriptions are maintained in `src/healthbridge/dictionary.py`.

Layers: `staging` (source-shaped), `core` (integrated), `marts` (analysis-ready), `dq` (data-quality measurements). The `raw` layer is files on disk (`data/raw/<run_id>/`, with `manifest.json`), not tables. The `ml` schema is reserved but empty: the forecasting study reads the marts panel and keeps its working data in memory and in result files.
